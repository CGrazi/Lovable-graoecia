# Grão & Cia Café

Crie uma loja virtual para a "Grão & Cia", que vende cafés especiais torrados. Deve ter catálogo de produtos com preço, página do produto, carrinho de compras e finalização de pedido por formulário. Visual quente e acolhedor.
